# FM26 官方特性地图

> 快照核实日期：2026-07-11。这里只用于快速定位。功能与平台状态仍须在回答时查官方最新页面。

## 完整版核心变化

- **Unity 技术基础**：FM26 完整版首次转向 Unity，带来新版 UI 与比赛日表现基础。
- **有球/无球双阵型**：战术系统分别设置 In Possession 与 Out of Possession formation，并加入与阶段相配的新职责及动态可视化。分析 FM26 战术时必须同时检查两套结构。
- **新版 UI**：以 Tiles 与 Cards 组织信息；Portal 取代旧版 Home/Inbox 中心逻辑；Bookmarks、增强 Search 与 FMPedia 帮助导航。
- **比赛日**：改进球员移动、动画混合、盘带 AI、球场材质、灯光、天气/天空、球场和转播呈现。不要把视觉变化自动等同比赛引擎数值变化。
- **招募**：TransferRoom 支持的 Requirements 用于向其他俱乐部表达需求；Pitch Opportunities 用于查看其他俱乐部的需求。传统球探判断仍然重要。
- **女足**：男足和女足存在于同一足球世界，可在执教生涯中切换。首发资料包括 14 个可玩女足联赛、11 个国家/地区、超过 36,000 名球员和 5,000 名非球员。男女足属性都使用 1–20，但量表分别相对于各自数据库，不能直接横向比较。
- **女足特有现实差异**：合同通常更短、解约条款更少、自由转会占比更高，并对财务、工资、补偿费、伤病、动作捕捉和 Newgen 生成作出相应建模。
- **授权**：英超首次完整授权；FM26 还包括 FIFA 世界杯相关授权及新增女足授权。具体比赛/俱乐部授权应查看最新官方清单。
- **存档继承**：官方特性页称，可在对应平台将 FM23 和 FM24 存档带入 FM26。Mobile 的继承规则单独确认，不要默认与完整版相同。

## 产品差异

| 产品 | 关键边界 |
|---|---|
| PC/Mac 完整版 | 深度最完整；回答菜单、战术、训练或数据功能时默认不得自动套用到其他版。 |
| FM26 Console | 与完整版有相似功能，但为主机体验优化并存在显著差异。先核实菜单与限制。 |
| FM26 Touch | 面向 Nintendo Switch；采用 Unity 时代的部分功能，但 UI、存档限制与深度不同。 |
| FM26 Mobile | Netflix 会员版本；FM26 系列中当时唯一未转向 Unity 的产品，功能与可加载范围不同。 |

在 Console、Touch 和 Mobile 中，同一国家的男足与女足联赛可能分别计入可加载国家限制。具体数量按产品官方页面核实。

## 易混淆点

- “FM26”不是单一功能集合；完整版、Console、Touch、Mobile 必须分开。
- 继承旧档不代表旧数据库会自动变成新开档数据库。回答球员/规则问题时确认存档来源。
- “有球/无球阵型”不是简单保存两套完全独立战术；解释时结合职责行为与转换过程。
- 游戏内翻译可能随语言包和补丁改变。先给中文含义，再附英文 UI 术语。
