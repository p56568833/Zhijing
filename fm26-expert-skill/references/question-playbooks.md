# 高频问题分析手册

## 战术诊断

最有价值的输入：有球阵型、无球阵型、每个角色/职责、球队指令、关键球员属性、对手形态、比赛截图、近 5–10 场机会质量而不只是比分。

按以下顺序排查：

1. **第一阶段出球**：中卫/门将是否有安全接应；是否被对手第一线压迫锁死。
2. **推进与宽度**：边路是否有人拉开；中场是否存在可接球的不同高度。
3. **最后一线占位**：禁区内人数、肋部占位、回撤与前插是否互相补足。
4. **丢球保护**：有球时身后留几人；边后卫同时前插是否暴露转换。
5. **无球压迫**：前场方向、压迫线与后防线是否匹配；是否给对手轻松越过第一线的出口。
6. **球员适配**：角色需要的决策、预判、无球、技术、速度和体能是否匹配。

一次只改 1–2 个高杠杆变量，保留对照样本。优先看射门位置、禁区触球、推进路径、被反击方式和比赛画面。

## 球员评估

不要用“属性总和”选人。先从任务反推能力组合：

- 角色硬需求；
- 决策、预判、镇定等对稳定性的影响；
- 身体条件与联赛强度；
- 位置/角色熟练度；
- 个性、稳定性、伤病史、合同、注册和成长环境；
- 球探报告的知识完整度与不确定区间。

对随机潜力球员说“在该数据库中可能有变化”。对用户存档未知的球员，不给伪精确的 PA/价格。

## 转会与合同

先确认窗口、预算、工资空间、董事会限制、注册/劳工证、球员兴趣、经纪人反馈与球队需求。分别给：立即可执行方案、备选路径、谈判退出点。FM26 可结合 Requirements 和 Pitch Opportunities，但不能替代球探与合同风险判断。

## 训练与青训

将训练效果拆成：赛程密度、训练设施、教练质量与工作量、训练单位、个人训练、比赛时间、疲劳/伤病风险、球员年龄与职业素养。不要承诺某个训练表“必涨属性”。密集赛程优先恢复与比赛准备；长期培养再讨论额外训练和位置转型。

## 星级与潜力

解释星级时强调相对性和评估误差。潜力星级下降可能来自阵容变强、评估人员变化、知识增加、年龄/发展变化，不等于 PA 被系统随意降低。

## 界面找不到功能

先确认产品和补丁，再让用户使用 FM26 Search、FMPedia 或 Bookmarks。若旧教程使用侧栏/Inbox/Home 路径，视为旧 UI 线索，不当作 FM26 路径。必要时根据用户截图定位。

## 回答示例骨架

**结论**：你现在最应先改 X，而不是同时重做整套战术。

**原因**：从你提供的无球阵型看，第一压迫线有两人，但对手三后场始终多一人，导致中场被迫前顶并暴露身后。

**操作**：调整一名前场角色的无球站位/压迫方向，或降低后续中场的盲目前顶；具体按钮按用户平台确认。

**验证**：连续观察 3–5 场对手从后场进入中场的方式、己方抢回位置和被打身后的次数。若问题不变，再动第二个变量。

**边界**：这是战术诊断建议，不是已公开的比赛引擎公式。
